# curl_cffi: HTTP client that impersonates a real browser's TLS fingerprint.
#   Yahoo's chart endpoint answers 429 to plain curl/requests from most
#   networks; impersonation is the only reliable way in, and it is what
#   yfinance itself uses underneath. We call the endpoint directly rather
#   than through yfinance because yfinance decodes prices into Python floats
#   before any of our code sees them, which ENGINE_RULES.md forbids.
